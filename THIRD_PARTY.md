# Third-party components

This repository contains integration files only. Download and accept each project's
license separately.

| Component | Official source | Included here? |
|---|---|---|
| OpenMW | https://github.com/OpenMW/openmw/releases | No |
| Mesa for Windows | https://github.com/pal1000/mesa-dist-win/releases | No |
| ReShade | https://reshade.me/ | No |
| DLSS5-Feeder | https://github.com/jlrouzies-fr/DLSS5-Feeder/releases | Source patch only |
| VORT shaders | Author's official repository/distribution | No |
| qUINT/MXAO | https://github.com/martymcmodding/qUINT | No |
| RHI | https://github.com/RankFTW/RHI/releases | No |
| NVIDIA DLSS | NVIDIA-authorized game/RHI distribution | No |
| Lossless Scaling (optional) | https://losslessscaling.com/ | No |

Morrowind game data and saves are not part of the kit. The installer only copies
third-party files supplied by the user; it does not download or redistribute them.

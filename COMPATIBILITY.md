# GPU compatibility

| GPU generation | Expected status | Project validation |
|---|---|---|
| RTX 20 series (Turing) | Community/experimental | Not yet tested |
| RTX 30 series (Ampere) | Community/experimental | **RTX 3090 passed** |
| RTX 40 series (Ada) | Community/experimental | Not yet tested |
| RTX 50 series (Blackwell) | Official DLSS 5 target hardware; kit remains experimental | Not yet tested |

The kit depends on a compatible NVIDIA driver, DLSS/RenoDX component combination,
Vulkan interop support, and enough performance for the selected resolution. A row
marked “expected” is not a guarantee that every board, driver, or component revision
works.

When reporting a result, include:

- exact GPU and driver;
- Windows version;
- OpenMW and Mesa versions;
- SHA-256 component manifest generated by the installer;
- resolution and window mode;
- `ReShade.log` and `dlss5-feed.log` with proprietary binaries omitted.

Start unvalidated cards at 1920x1080. External Lossless Scaling/LSFG can be tested
after the native kit is stable, but report it separately because it changes frame
pacing and displayed FPS rather than the in-process integration.
